# Fixture catalog

This directory is the bench's ground-truth corpus. Each `<name>.pdf` is
matched by `<name>.expected.txt` (alphanumeric CER reference) and
`<name>.expected.json` (DocumentGraph ground truth). The bench's
`--fixtures` flag points here.

Two layers:

1. **Shipped fixtures (committed)** — 9 PDFs total, all with both ground-truth
   sidecars. Re-runnable via the two generator scripts; zero network required.
2. **Public benchmark subsets (downloaded on demand)** — `./fetch_public_benchmarks.sh`
   pulls a representative sample from OmniDocBench, ParseBench, and getomni-ai/ocr-benchmark.
   NOT committed; downloads land in `fetched/` (~100 MB total).

## Shipped fixtures

| Fixture | Class | What it tests | Source |
|---|---|---|---|
| `smoke.pdf` | Born-digital, 2 paragraphs | Sanity: every inference target should recover two clean paragraphs. Used for harness dev. | Generated by `make_smoke.py` |
| `reportlab-invoice.pdf` | Born-digital, single page | Native-text happy path; verifies the harness's `native_hits` counter and the fast lane. | Generated by `make_adversarial.py` |
| `reportlab-ascii85.pdf` | Born-digital, ASCII85 stream | Same content as the invoice but encoded with `/ASCII85Decode`. Most native parsers handle it; some don't. Forces the OCR fallback path on those. | Generated by `make_adversarial.py` |
| `scanned-text.pdf` | Single-page scan, no text layer | Forces the OCR fallback. The "easy scan" — high-DPI, clear text. | Generated by `make_adversarial.py` |
| `mixed-native-and-scanned.pdf` | 2-page: page 1 native text + page 2 raster | Page-level routing: native extraction must succeed on page 1; OCR must fire on page 2. The `native_preservation` graph-fidelity score is 0 if a VLM rewrites page 1 as OCR text. | Generated by `make_adversarial.py` |
| `two-column.pdf` | Two-column body text | Reading-order preservation: column 1 must come before column 2, top-to-bottom within each column. | Generated by `make_adversarial.py` |
| `borderless-table.pdf` | 3×3 table with no visible borders | Table-cell recovery without visual separators. Layout model must use whitespace. | Generated by `make_adversarial.py` |
| `rotated-15deg.pdf` | Single page rotated 15° | Rotation handling: Tesseract without OSD fails; pdftotext fragments output (CER ~0.7 on the un-rotated ground truth); Transcode native reads rotated text correctly. | Generated by `make_adversarial.py` |
| `scanned-fuzzy.pdf` | Single-page scan + Gaussian blur (radius=2.5) | Noise-robust OCR. Separates native-OCR from image-cleanup-OCR. | Generated by `make_adversarial.py` |

All eight adversarial PDFs are 1–70 KB and live in this repo. To regenerate
them:

```bash
python3 make_adversarial.py    # regenerates the 8 adversarial PDFs
python3 make_expected_json.py  # regenerates the .expected.json sidecars
python3 make_smoke.py          # regenerates smoke.pdf + smoke.expected.{txt,json}
```

The `.expected.txt` files are hand-curated alphanumeric-lowercase reference
texts. The `.expected.json` files are auto-generated from
`make_expected_json.py` based on a per-fixture structure map; they project
through `superdocuments::graph::from_ocr_markdown` so the bench's
graph-fidelity scoring has a coherent reference.

## Public benchmark subsets

The `fetch_public_benchmarks.sh` script downloads a small representative sample
from three public benchmarks. None of these are committed to the repo — they
land in `fetched/` (gitignored). Re-run the script on any host with internet
access.

### OmniDocBench (opendatalab/OmniDocBench)

- **Source**: <https://huggingface.co/datasets/opendatalab/OmniDocBench>
- **License**: dataset downloadable, but the *benchmark* is research-only
  per the upstream README. Use for benchmarking, not commercial evaluation
  of the corpus itself.
- **Size of full dataset**: ~42 MB JSON + ~7 GB PNG (1,651 pages across 10
  document types and 5 languages).
- **What we download**: 30 PNG pages, stratified by document type (3 per
  major prefix), plus a trimmed slice of `OmniDocBench.json` filtered to
  the selected pages. Total ~12 MB.
- **Format on disk**: `omnidocbench/images/<doc>_page_<N>.png`,
  `omnidocbench/annotations/OmniDocBench.json` (filtered).
- **Note**: OmniDocBench is **images**, not PDFs. To run our bench against
  it, you'd want a separate image-to-PDF wrapper (or an image-target
  variant of the bench). For now we ship the image set for inspection
  only; the bench consumes PDFs.

### ParseBench (llamaindex/ParseBench)

- **Source**: <https://huggingface.co/datasets/llamaindex/ParseBench>
- **License**: Apache-2.0 (dataset) + benchmark code Apache-2.0. Commercial
  use OK.
- **Size of full dataset**: 9.5 MB `layout.jsonl` + 55 MB `text_content.jsonl`
  + 1.6 MB `chart.jsonl` + 3.1 MB `table.jsonl` + 1.8 MB
  `text_formatting.jsonl`. PDFs live under `docs/{text,table,layout,chart}/`.
- **What we download**: 5 PDFs (one per category when possible), plus the
  full rule JSONL files sliced to the selected docs (~3 MB total). The
  JSONL rules drive our `.expected.txt` generation.
- **Format on disk**: `parsebench/docs/<text|table|layout|chart>/<name>.pdf`
  + `parsebench/docs/.../<name>.expected.txt` (auto-generated from the
  bag-of-sentences rule) + `parsebench/annotations/{text_content,...}.jsonl`
  (sliced to the selected PDFs).
- **Note**: ParseBench is what `run-llama/ParseBench` itself evaluates. The
  subprocess target added in this bench can be compared apples-to-apples
  against the published ParseBench leaderboard.

### getomni-ai/ocr-benchmark

- **Source**: <https://huggingface.co/datasets/getomni-ai/ocr-benchmark>
- **License**: MIT. Commercial use OK.
- **Size of full dataset**: 8.3 MB `metadata.jsonl` + image directory.
- **What we download**: 5 sample images + the metadata file.
- **Format on disk**: `getomni/images/<name>.png` +
  `getomni/metadata.jsonl` (8 MB).
- **Note**: same caveat as OmniDocBench — images, not PDFs. The bench's
  current target list speaks OpenAI-compat / HTTP / subprocess. Image OCR
  targets are a follow-up.

## Running the bench against the fetched corpus

```bash
# ParseBench has PDFs the bench can directly consume:
cargo run --release --manifest-path ../Cargo.toml -- \
  --fixtures fetched/parsebench/docs \
  --out fetched/parsebench-bench.json \
  --warmup 1 --samples 3 --iterations 2

# OmniDocBench / getomni are images; treat the bench's image-target
# variant (planned, not in scope this session) as the entry point.
```

## What this directory does NOT contain

- **Commercial OCR benchmark data** (Mistral OCR, Google Document AI, AWS
  Textract): commercial APIs charge per page and ship their own evaluation
  harness. We use the public open-weight datasets above.
- **The full OmniDocBench / ParseBench corpora**: the 12 GB+ of full
  annotations is too large to vendor. Use the upstream benchmarks'
  published runner scripts (`parse-bench run <pipeline>`,
  `docling-eval evaluate`) for full-corpus runs; use this fixture set
  for fast iteration.
- **Synthetic/augmented fixtures**: not needed. The 9 committed PDFs
  cover born-digital, scanned, mixed, two-column, borderless table,
  rotated, fuzzy scan, and ASCII85-encoded — the full inspector-recommended
  matrix.
