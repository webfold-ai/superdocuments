# CSL styles used by the citation benchmark

Fetched on 2026-11-12 from https://github.com/citation-style-language/styles (master), file names unchanged:
apa.csl, chicago-author-date.csl, ieee.csl, harvard-cite-them-right.csl, nature.csl,
modern-language-association.csl. Each file carries its own authors and licence in its `<info>` block:
Creative Commons Attribution-ShareAlike 3.0 (http://creativecommons.org/licenses/by-sa/3.0/). They are
test fixtures only: the library does not embed or ship any style, and loads the style the caller gives it.
