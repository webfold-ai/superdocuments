# Engines and programs

The first published program [@lovelace1843] targeted a mechanical engine. @hopper1952 built the first compiler, and @knuth1984 [chap. 2] later formalised literate programs. See also [e.g., @dijkstra1968; @hoare1969].

# Languages

Structured programming [@dijkstra1968] and abstract data types [@liskov1987] shaped languages. A survey by @backus1978 appeared in [-@backus1978].
